# Vision — ilabuporto-design-system

## Problem

Every iLab — UPdigital — U.Porto project builds its own UI components from scratch,
leading to inconsistent branding, duplicated effort, and maintenance burden.

## Solution

A shared, versioned, and documented component library that all U.Porto digital
services can install via npm and consume with a single import.

## Value Proposition

- **Consistent brand** — single source of truth for colours, typography, spacing
- **Faster delivery** — projects skip UI component development
- **Accessible by default** — WCAG AA baked into every component
- **Dark mode included** — no extra effort per project

## Target Audience

Development teams building U.Porto digital services (websites, dashboards,
internal tools, student-facing apps).

## Success Metrics

- Published to npm (public or GitHub Packages)
- Used by ≥ 2 iLab projects
- ≥ 80% component test coverage
- CI pipeline green for every PR
